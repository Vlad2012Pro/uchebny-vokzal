# Учебный вокзал

Мини-приложение для конспектов. Каждый конспект — обычный файл `.md` в выбранной вами папке.

- Правки сохраняются в файл автоматически.
- Удалили конспект в приложении — файл уходит в корзину системы (его можно вернуть).
- Изменили или добавили `.md` файл в папке снаружи — при возвращении в окно приложения всё подтянется.

## Как получить установочные файлы через GitHub

1. Создайте на github.com новый репозиторий (например, `uchebny-vokzal`).
2. Загрузите в него все файлы этого проекта (включая скрытую папку `.github`).
   Через терминал:
   ```
   git init
   git add .
   git commit -m "Первая версия"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/uchebny-vokzal.git
   git push -u origin main
   ```
3. Выпустите версию — это запустит сборку:
   ```
   git tag v1.0.0
   git push origin v1.0.0
   ```
   (или в GitHub: Releases → Draft a new release → создать тег `v1.0.0`)
4. Через 5–10 минут во вкладке **Actions** сборка завершится, а в **Releases** появится черновик с файлами:
   - Windows: `...-win-x64.exe` (установщик) и portable-версия
   - macOS: `.dmg`
   - Linux: `.AppImage`
   Откройте черновик и нажмите **Publish release**.

Без тега можно запустить сборку вручную: **Actions → Build → Run workflow**. Готовые файлы будут в разделе Artifacts.

> Приложение не подписано, поэтому Windows может показать «Защитник Windows предотвратил запуск» (нажмите «Подробнее → Выполнить в любом случае»), а macOS — потребовать открыть через ПКМ → «Открыть».

## Запуск у себя без GitHub

Нужен [Node.js](https://nodejs.org).
```
npm install
npm start
```
Сборка установщика локально: `npm run dist` (результат в папке `dist`).
